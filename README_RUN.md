# Запуск игры Boulder Dash

## Требования к системе

Для сборки проекта необходимы следующие компоненты:
- Qt 5.15 или новее (модули Core, Gui, Qml и Quick)
- CMake 3.16 или новее
- Ninja
- Компилятор C++ (GCC или Clang)
- Среда разработки (например, Qt Creator или Visual Studio Code)

## Шаги для сборки и запуска

### 1. Установка зависимостей (Ubuntu/Debian)
```bash
sudo apt update
sudo apt install cmake ninja-build build-essential qtbase5-dev qtdeclarative5-dev \
    qml-module-qtquick2 qml-module-qtquick-window2 qml-module-qtqml qml-module-qtqml-models2
```

### 2. Создание директории для сборки
```bash
cmake -S . -B build-qt5 -G Ninja -DCMAKE_BUILD_TYPE=Debug
cmake --build build-qt5
```

### 3. Запуск игры
```bash
./build-qt5/boulderdash
```

## Альтернативные способы запуска

Если у вас нет прав на установку пакетов, вы можете:
1. Использовать Qt Creator для открытия проекта
2. Запустить из Visual Studio Code с поддержкой CMake
3. Использовать готовый бинарный файл (если он уже был собран)

## Управление в игре

- Стрелки или WASD: движение по игровому полю
- Пробел: копать вниз-вбок
- Esc или P: пауза / продолжение; в настройках — назад. Выход доступен в меню.

## Меню и настройки

При запуске выберите «Начать игру». Кнопки «Пауза» и «Настройки» доступны в игровом окне. Из меню можно продолжить игру, начать новую или выйти.

Настройки сохраняют тему, героя, разрешение анимации и интервал кадров (80/140/220 мс). Скорость игры не меняется. На паузе физика и таймеры Кирпичей остановлены; после продолжения таймеры сохраняют оставшееся время. Новая игра сохраняет оформление и сбрасывает прохождение.

В стандартном окружении H2 файл настроек — `~/.config/Majorov/BoulderDash.conf`. Новое учебное руководство: `/home/majorov/docs/LEARNING_06.md`.

## Оформление

- Кнопка «Тема» меняет оформление тайлов.
- Кнопка «Герой» переключает классического Персонажа, двух космонавтов и робота.
- «Галерея тайлов» открывает сравнение тайлов и Персонажей; раздел Персонажей находится ниже тайлов, доступна прокрутка.
- Отдельный запуск галереи: `./build-qt5/boulderdash --tile-gallery`.
- На H2 с локальными зависимостями используйте `./build-qt5/run.sh`, для галереи — `./build-qt5/run.sh --tile-gallery`.

## Текущая реализация

Игра реализована с использованием:
- C++ для игровой логики
- QML для визуализации
